# Trouspy

Trouspy est un projet de découverte touristique qui associe des guides et contenus structurés
à des applications mobiles et web.

Notre ambition : aider les voyageurs à découvrir les destinations et à consulter des
informations touristiques claires et utiles.

## Ce que nous construisons

| Chantier | Rôle |
|---|---|
| Données touristiques | Organiser et vérifier les contenus, lieux et guides |
| Site institutionnel | Présenter Trouspy et son univers |
| Application mobile | Proposer une expérience de découverte sur téléphone |
| Application web | Rendre les services accessibles dans le navigateur |
| API | Relier les applications aux données |

## État du projet

Trouspy est en préparation de son MVP. Cette page présente le projet ; les dépôts de travail
sont actuellement réservés à l'équipe.

Les liens vers le site et les réseaux sociaux seront ajoutés lors de leur ouverture.
